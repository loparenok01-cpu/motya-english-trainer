МОТЯ — наборы слов для учителя и ученика, версия 1.0
========================================================

Что внутри архива
-----------------
  motya.html                         — файл УЧЕНИКА (игра, прогресс, отчёт)
  motya-teacher.html                 — файл ПРЕПОДАВАТЕЛЯ (подготовка наборов)
  ПАМЯТКА_ученику.txt                — короткая инструкция для ученика (отдайте классу)
  irregular_verbs_with_transcription.csv — пример словаря (14 неправильных глаголов)
  README.txt                         — эта инструкция

Оба html-файла автономные: их можно открыть двойным щелчком, сервер и интернет
не нужны. Главное — положить оба файла в одну папку.


Короткий порядок работы для учителя
-----------------------------------
1. Откройте motya-teacher.html.
2. Нажмите «+ Из базы глаголов» — получите готовый набор из 99 неправильных
   глаголов с транскрипциями, либо «+ Пустой набор» и заполните сами.
3. В поле «Где лежит ученический файл» укажите motya.html (по умолчанию уже
   так). Если раздаёте файлы по классу — укажите, где он будет лежать
   (например, ссылку на облачную папку или общий диск).
4. Нажмите «Скопировать ссылку» — это основной способ выдачи.
   Если набор очень большой и ссылка не помещается (предупреждение при
   4000 символах) — скопируйте «Код набора» и пришлите его вместо ссылки.
5. Отправьте ссылку (или код) ученику любым способом: мессенджером, почтой,
   QR-кодом, на карточке.
6. Ученик открывает motya.html, вставляет ссылку/код, вводит своё имя и жмёт
   «▶ Начать».

Ссылку можно проверить прямо у себя: «Открыть в ученическом файле ↗».


Что видит ученик
----------------
- Список своих наборов с прогрессом («освоено X из Y»).
- Пять режимов игры: RU→EN с вводом, EN→RU, карточки (визуальный выбор),
  V1→V2,V3,перевод; порядок «по порядку» или «в случайном порядке»;
  режим «на время» с выбором длительности.
- Паук-полиглот ползёт по паутинке по мере правильных ответов.
- В конце — очки, разбор ошибок и кнопка «📥 Отчёт для учителя»:
  ученик скачивает CSV и присылает вам.


Форматы, которые понимает преподавательский файл
------------------------------------------------
Вставка текстом (кнопка «Вставить набор текстом»):
  - через «|»:      будить | wake | woke | woken
  - через «;»:      Русский;V1;Транскрипция V1;V2;Транскрипция V2;V3;Транскрипция V3
  - CSV/TSV:        то же, с заголовком или без
  - JSON:           {"ru":"будить","en":["wake","woke","woken"],
                     "trans":["[weɪk]","[wəʊk]","[ˈwəʊkən]"]}
Загрузка файла: .json, .csv, .txt, .tsv (перетащить можно и прямо в окно).
Выгрузка: «⬇ Набор в JSON» и «⬇ Набор в CSV».

Транскрипции необязательны: если их нет, игра просто их не показывает.
Транскрипций должно быть столько же, сколько форм глагола.


Полезное в редакторе
--------------------
- Название и дата набора сохраняются автоматически (пишется «сохранено»).
- ID набора не меняется при правках — прогресс учеников сохраняется.
- Строки с пустым английским словом помечаются красным и в выдачу не идут;
  кнопка «только готовые» отсеивает их в один клик.
- «⧉ Копировать набор» — копия получает новый ID (не перепишет чужой
  прогресс), состав переносится целиком.
- «✕ Удалить набор» — требует подтверждения.
- Наборы хранятся в этом браузере (localStorage). Очистка данных браузера
  удалит их — выгружайте важное в JSON.


Как переделать набор из 99 глаголов под свой класс
-------------------------------------------------
1. «+ Из базы глаголов» — создаётся набор из 99 неправильных глаголов.
2. Нужен только свой список? «⧉ Копировать набор» — исходная база останется
   нетронутой, работайте с копией.
3. Удалить лишние строки:
   - поляйте «поиск по строкам» нужным словом (например «бежать») —
     таблица покажет только подходящие строки и счётчик «N из 99»;
    - раскройте выпадающий список рядом и выберите порядок: по русскому
      (А → Я / Я → А), по английскому (A → Z / Z → A) или по заметкам
      (пустые заметки при сортировке А → Я идут первыми);
   - поставьте галочку в шапке таблицы — выберутся все видимые строки;
   - «Удалить выбранные» (с подтверждением).
   Галочка есть и у каждой строки — можно выбирать по одной.
   Кнопка «✕» справа удаляет одну строку.
   Поиск и сортировка меняют только показ: состав набора и порядок строк
   в самом наборе не меняются.
4. Добавить свои глаголы: раскройте «➕ Добавить свои глаголы в этот набор»,
   впишите по строке на слово — «бежать | run | ran | run» — и нажмите
   «Добавить в набор». Свои слова дописываются в конец списка.
   Несколько слов разом можно вставить и кнопкой «Вставить в конец»
   (текстовое поле вставки — наверху, в разделе «Вставить набор текстом»).
 5. Проверьте мету над таблицей: «готово к выдаче: N». Если есть красные
    строки — либо заполните их, либо нажмите «только готовые».
 6. Выдавайте ссылку как обычно.


Как выдавать набор по частям (пачками)
--------------------------------------
Набор один, id не меняется — у ученика один и тот же список слов
пополняется постепенно («+N новых слов»), прогресс по ранее выученным
словам сохраняется.

1. Отметьте уже отправленные слова: выделите их галочками и нажмите
   «✓ Отметить отправленными» — в заметку допишется отметка с датой
   («✓ 06.10.2026»), ваш текст в заметке сохранится. Счётчик под
   таблицей показывает «отмечено: N из 99».
2. Следующую партию соберите фильтром: выпадающий список «Заметки: …»
   → «Только неотправленные» → галочка в шапке таблицы — все видимые
   выбраны. Или отметьте нужные строки вручную.
3. В блоке «Выдать ученику» выберите «Что выдавать»:
   - «Весь набор» — все строки, как раньше;
   - «Только выбранные строки» — только отмеченные галочками;
   - «Только не отправленные» — всё, кроме уже отправленного.
   Счётчик рядом показывает, сколько слов уйдёт ученику.
4. Скопируйте ссылку (или код) и отправьте. Прогресс ученика
   привязан к набору и не теряется.
5. Снова отметьте отправленные (шаг 1) — следующая партия их не заденет.
6. «Снять отметку» возвращает заметку к исходному тексту.
7. «⧉ Копировать выбранные» — если всё же нужен отдельный набор-пачка
   (со своим id, прогрессом и ссылкой).


Прогресс ученика
----------------
- Хранится только в браузере ученика, на его компьютере. Сервера нет,
  ничего никуда не отправляется.
- Привязан к паре «набор + имя ученика»: разные дети не мешают друг другу.
- Имя можно выбрать из списка (подсказка заполняется автоматически).
- «🏆 Таблица рекордов» показывает результаты по этому устройству.
- «📥 Отчёт для учителя» в конце игры — CSV для вашей проверки.


Ограничения версии 1.0
----------------------
- Нет озвучки слов (синтез речи) и распознавания речи (намеренно).
  Есть только короткие звуковые эффекты — их выключает кнопка 🔊 в шапке.
- Прогресс не синхронизируется между устройствами: если ученик меняет
  компьютер, прогресс остаётся на старом.
- Ссылка выдаётся по одному набору; классом выдача пока вручную.
- База глаголов встроена в файл преподавателя, интернет не нужен.


Если что-то не работает
-----------------------
- «Ссылка слишком длинная» — отправьте ученику код набора вместо ссылки.
- Ученик пишет, что ссылка не открывается — убедитесь, что рядом лежит
  motya.html, и проверьте ссылку кнопкой «Открыть в ученическом файле ↗».
- Пропал список наборов — скорее всего очищены данные сайта в браузере;
  восстановите из выгруженного JSON.
- Файл не открывается двойным щелчком — откройте правой кнопкой →
  «Открыть с помощью» → браузер (Chrome, Edge, Firefox, Safari).

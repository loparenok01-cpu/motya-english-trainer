## Положительные находки

| № | Находка | Детали |
|---|---|---|
| 1 | Нулевой сетевой attack surface | Ни одного внешнего `script src` / `link href=http`, ни `fetch`/`XMLHttpRequest`; всё инлайн, приложение работает полностью офлайн из файла |
| 2 | Централизованное экранирование вывода | `escapeHtml`/`esc` во всех HTML-конкатенациях; таблица строк преподавателя — через `input.value`/`textContent` |
| 3 | Защищённый разбор непроверенных данных | Проверка версии формата `FMT`; `atob`/LZSS/`JSON.parse` в try/catch; обрыв потока — throw |
| 4 | Валидация настроек | Клампы `wordLimitN` 1…999, whitelist `validWordLimit`, таймер через `select` |
| 5 | Устойчивость к отказам хранилища | Все обращения к localStorage в try/catch |
| 6 | Гигиена файлов | `safeName`, BOM для Excel, кавычки в CSV, защита базового набора от удаления |
| 7 | Доступность | `aria-live`, `aria-label`, `prefers-reduced-motion`, тач-цели 60–65 px |
| 8 | Автотесты в репозитории | `tests/`: ядро 108, сверка CORE 14, ученик 139, преподаватель 211 (итого 472); запуск `cd tests && npm install && npm test` |

## Известные ограничения

| № | Ограничение | Детали |
|---|---|---|
| 1 | Офлайн-архитектура без сервера и БД | Нет аутентификации ролей; доступ к данным определяется физическим доступом к браузеру |
| 2 | Один браузер — один ученик | Прогресс по свободному имени без PIN (Р-1 принято by design); на общем компьютере возможен доступ к чужому прогрессу |
| 3 | Прогресс привязан к браузеру | localStorage не синхронизируется между устройствами |
| 4 | Данные набора читаемы по ссылке | base64+LZSS — обфускация, не шифрование; предупреждение в README |
| 5 | Классический CSV | BOM + кавычки + нейтрализация формил (выполнена 11.10.2026) |
| 6 | Ручная выкладка | Нет CI; сборка учителя — локальный `node`-скрипт |
| 7 | Единственный разработчик | Нет ревью и второй линии поддержки |

# Отчёт аудита релиз-кандидата «Мотя»

- **Дата:** 11.10.2026
- **Объекты аудита:** `motya.html` (игра ученика, 1433 строки), `motya-teacher.html` (редактор преподавателя, 1246 строк), вспомогательные файлы репозитория
- **Метод:** статический анализ кода, greps, чтение логики разбора ссылок/CSV/вывода текста, верификация через CDP (эмуляция мобильных экранов), прогон автотестов (414 зелёных)
- **Вне релиза:** `Мотя_глаголы.html` (легаси-файл, не входит в zip-релиз, оценён отдельно)

## Положительные находки

| № | Находка | Детали |
|---|---|---|
| 1 | Нулевой сетевой attack surface | Ни одного внешнего `script src` / `link href=http`, ни `fetch`/`XMLHttpRequest`; всё инлайн, приложение работает полностью офлайн из файла (`http://www.w3.org/2000/svg` — только XML-namespace) |
| 2 | Централизованное экранирование вывода | `escapeHtml`/`esc` (экранирует `& < > " '`) во всех HTML-конкатенациях; таблица строк преподавателя строится через `input.value`/`textContent` |
| 3 | Защищённый разбор непроверенных данных | Проверка версии формата `FMT` до разбора; `atob`/LZSS/`JSON.parse` в try/catch; повреждённый поток LZSS кидает ошибку, а не зацикливается (`motya.html:347–367`) |
| 4 | Валидация настроек | Клампы `wordLimitN` 1…999, whitelist `validWordLimit`, таймер через `select` с фиксированными значениями, `parseInt || 120` |
| 5 | Устойчивость к отказам хранилища | Все обращения к localStorage в try/catch: переполнение квоты не роняет игру |
| 6 | Гигиена файлов | `safeName` для имён скачиваемых файлов, BOM для Excel, кавычки в CSV-ячейках с разделителями, защита базового набора от удаления |
| 7 | Доступность | `aria-live` на обратной связи, `aria-label` у поля ответа, `prefers-reduced-motion` в обоих файлах, крупные тач-цели (60–65 px) в игре |
| 8 | 414 автотестов на jsdom | Преподаватель 205, ученик 111, core 98; сид-данные, миграции, регрессии |

## Известные ограничения

| № | Ограничение | Детали |
|---|---|---|
| 1 | Офлайн-архитектура без сервера и БД | Нет аутентификации ролей; доступ к данным определяется только физическим доступом к браузеру (см. Р-1, Р-2) |
| 2 | Прогресс привязан к браузеру | localStorage не синхронизируется между устройствами; перенос прогресса возможен только вручную через localStorage |
| 3 | Данные набора читаемы по ссылке | base64+LZSS — обфускация, а не шифрование; в набор нельзя класть персональные данные (предупреждение в README) |
| 4 | Классический CSV | Корректное открытие в Excel требует BOM и кавычек; нейтрализация формул (Б-1) до исправления не выполняется |
| 5 | Ручная выкладка | Релиз распространяется файлами/zip и GitHub Pages; нет CI/автоматической сборки (сборка учителя — локальный `node`-скрипт) |
| 6 | Единственный разработчик | Ревью кода и вторая линия поддержки отсутствуют |

## Финальное решение о готовности релиза

**Не готов к публикации.**

Критических уязвимостей нет, но к публикации необходимо закрыть как минимум две находки со средним риском, затрагивающие реальные сценарии:

- **Б-1 (CSV-формулы)** — вектор «ученик → учитель» через выгружаемый отчёт;
- **Р-1 (PIN / подсказка имён)** — вектор «ученик → ученик» на общем компьютере.

Остальные находки (Р-2, Л-1, В-1, Б-2, М-1, Т-1, Т-2) рекомендуется закрыть в ближайшем релизе, но они не блокируют публикацию после исправления Б-1 и Р-1.

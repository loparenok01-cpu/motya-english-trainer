Мотя учит английские слова

Учебный тренажёр для заучивания неправильных глаголов (и других слов) английского языка через игру и прямо в браузере.

Задача и контекст

Задача

Сделать приложение, чтобы за пару минут собрать набор слов, выдать ссылку с заданием, чтобы ученики тренировались каждый в своем браузере — без сервера, установки и регистрации.

Целевая аудитория

Учителя английского языка и их родители и сами ученики: учитель (родитель или сам ученик) готовит набор слов для запоминания в преподавательском редакторе приложения, ученики играют в браузере, прогресс хранится отдельно на каждого ученика, если их несколько.

Проблема

Готовые сервисы требуют регистрации и интернета, перегружены лишним, а свои слова раздают через таблицы и печать — нет быстрого способа выдать свой список и получить обратную связь.

Решение

Решение

Два самодостаточных HTML-файла: преподавательский редактор вшивает данные набора прямо в ссылку или код, ученический файл открывает её и превращает в игру; всё хранится в localStorage, сервер не нужен.

Основные функции

5 режимов игры (ввод, карточки, EN→RU, три формы глаголов), выбор количества слов и режим «на время»; база неправильных глаголов с транскрипциями; пакетная выдача слов с отметками; отчёт ученика в CSV; прогресс и рекорды.

Использованные инструменты

Чистые HTML/CSS/JavaScript без зависимостей и сборщика, localStorage, автотесты на jsdom (414 проверок), Claude Code (opencode) для написания и отладки кода.

Результат

Рабочий комплект: созданный набор слов (в редакторе есть возможность добавления, редактирования слов, копирования наборов и их части), выдаётся ученику/ученикам ссылкой за минуту, две страницы работают офлайн и распаковываются одним архивом. Загружен стартовый набор: 102 неправильных глагола (формы V1, V2, V3) с транскрипциями.
